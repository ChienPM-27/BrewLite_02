\noindent\textit{Ghi chú thiết kế API:} Nhằm tối ưu hóa hiệu năng truyền tải và hạn chế hiện tượng roundtrip mạng dư thừa, hệ thống tích hợp phân loại danh mục trực tiếp vào \texttt{GET /products} (thay vì tách riêng \texttt{GET /categories}), và nhúng danh sách topping khả dụng vào phản hồi chi tiết món \texttt{GET /products/:id} (thay vì tách riêng \texttt{GET /toppings}). Trạng thái giao dịch thanh toán được truy vấn trực tiếp qua chi tiết đơn hàng \texttt{GET /orders/:id} thay vì tạo endpoint độc lập \texttt{GET /payments/:id}.

Mọi phản hồi thành công từ hệ thống đều được chuẩn hóa qua \texttt{TransformInterceptor} theo cấu trúc:
\begin{lstlisting}[language=Java]
{
  "success": true,
  "data": { ... },
  "message": "Thong bao thanh cong",
  "timestamp": "2026-10-25T10:00:00.000Z"
}
\end{lstlisting}

Mọi phản hồi lỗi đều được chuẩn hóa qua \texttt{AllExceptionsFilter} theo cấu trúc:
\begin{lstlisting}[language=Java]
{
  "success": false,
  "statusCode": 400,
  "message": "Thong tin loi chi tiet",
  "error": "Bad Request",
  "timestamp": "2026-10-25T10:00:00.000Z",
  "path": "/api/v1/orders"
}
\end{lstlisting}
